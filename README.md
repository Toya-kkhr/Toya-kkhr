iOS と Web の両方を書く個人開発者です。
企画・設計から実装・リリースまで一人で通すスタイルで、SwiftUI のネイティブアプリと Next.js / Expo のクロスプラットフォーム開発を行き来しています。

## 🚧 いま作っているもの

<table>
<tr>
<td width="50%" valign="top">

### 🗺 ロケハン！
**聖地・ロケ地の AI 特定マップ × 巡礼フォトスタンプ**

アニメや映画のシーンのスクショを貼ると AI が撮影地を特定してピンを立て、現地で同じ画角で撮るとスタンプになる iOS アプリ。

`SwiftUI (MVVM + @Observable)`
`Supabase (Postgres + Edge Functions)`
`Claude API` `XcodeGen`

</td>
<td width="50%" valign="top">

### 🔒 アルクロック
**歩かないと娯楽アプリが開かない iOS アプリ**

1 日の歩数目標をマイルストーンに分割し、到達するたび「時間バンク」へ利用時間を付与。使い切ると再ロック。判定は HealthKit の歩数で自動、自己申告は不可。

`Swift 6` `FamilyControls` `DeviceActivity`
`HealthKit` `Swift Testing`

[**→ プロダクトサイト**](https://toya-kkhr.github.io/arukulock-site/)

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📔 LifeLogue
**ライフログ × 日記型エンタメ SNS**

Web と Mobile が同一の REST API を共有するモノレポ構成。型・バリデーション・日付ロジックを共有パッケージへ寄せ、クロスプラットフォームの一貫性を担保。

`Next.js 16` `React 19` `Expo SDK 54`
`Turborepo` `pnpm` `Prisma 7` `Supabase`

[**→ Web アプリ**](https://life-logue-web.vercel.app)

</td>
<td width="50%" valign="top">

### 🚶 walkingdom

`Swift` `SwiftUI`
